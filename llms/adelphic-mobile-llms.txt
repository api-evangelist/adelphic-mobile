# Adelphic (Viant DSP)

> Adelphic is an enterprise demand-side platform (DSP) for programmatic advertising, founded as a mobile-first programmatic buying platform and acquired by Viant Technology in 2017. It lets marketers plan, buy, and measure omnichannel campaigns across Connected TV, linear TV, mobile, desktop, streaming audio, and digital out-of-home from a single self-service interface, using Viant's people-based Household ID for identity resolution.

This llms.txt was generated by the API Evangelist enrichment pipeline from the profile in apis.yml and the artifacts in this repository. Adelphic is an enterprise SaaS platform with a hosted UI and a customer-gated knowledge base rather than a public developer API. The API host `api.adelphic.com` (and its alias `api.viantinc.com`) returns HTTP 401 with `WWW-Authenticate: Basic realm="Adelphic"` on every path, including `/openapi.json` and `/.well-known/*`. No OpenAPI, AsyncAPI, GraphQL SDL, MCP manifest, or A2A agent card is published on any Adelphic or Viant host.

## API
- Base host: `https://api.adelphic.com` — enterprise only, HTTP Basic auth, no public OpenAPI, reference, SDK, CLI, sandbox, or pricing.
- Alias host: `https://api.viantinc.com` — identical `Basic realm="Adelphic"` challenge.
- `https://www.adelphic.com` is a legacy JavaScript redirect shell mapping retired Adelphic, Specific Media, Vindico and Adviva domains onto viantinc.com pages; every content path returns 404.
